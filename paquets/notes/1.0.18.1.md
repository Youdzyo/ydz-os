# YDZ OS 1.0.18.1 — Correctif Internet (IPv4)

**Correctif.** Le Pi pouvait afficher « GitHub injoignable : pas d'Internet ? » alors qu'Internet fonctionne. Beaucoup de box (Livebox…) annoncent une adresse **IPv6** qui ne marche pas ; le Pi attendait dessus au lieu de basculer sur l'IPv4.

### Corrigé
- Tous les téléchargements de la tour (mises à jour, agenda, météo, test de débit, bloqueur de pub) utilisent désormais l'**IPv4 en priorité** — comme on le faisait déjà pour les mises à jour système. Plus de « GitHub injoignable » à cause de l'IPv6.

### À faire après l'installation
- Si les mises à jour automatiques étaient bloquées : installer ce correctif **à la main** une fois (Réglages → Mises à jour → « Installer un fichier de mise à jour »), puis rappuyer sur « Rechercher des mises à jour ». La suite se fera toute seule.
