# YDZ OS 1.0.20.1 — Correctif Canal Claude

**Correctif.** Le « Canal Claude » (Réglages › Agents) affichait une erreur **« too many values to unpack (expected 2) »** et ne fonctionnait pas : les agents que Claude fait tourner dans l'appli ne pouvaient pas apparaître sur l'écran de la tour.

> Installer après la 1.0.20.

### Corrigé
- **Canal Claude** : le flux ntfy renvoie trois éléments (code, en-têtes, corps) mais le code n'en lisait que deux, ce qui faisait planter chaque tour de lecture (l'erreur s'affichait dans les Réglages). Le flux est de nouveau lu correctement — les agents signés de l'appli Claude peuvent s'afficher sur l'écran.

### Sécurité
- Le correctif ne fait que **rétablir** le comportement déjà prévu et déjà audité du Canal Claude (affichage seul, signature HMAC obligatoire, rien n'est exécuté). Un contrôle offensif ciblé a été mené sur le chemin remis en service : flux ntfy malformé, événements piégés, signatures forgées et un flot de 100 000 lignes sont tous rejetés sans planter — seul un message correctement signé s'affiche. Rien de nouveau à colmater ; test de non-régression ajouté (421 tests au vert).

### À faire après l'installation
- Rien : `apres.sh` redémarre le service tout seul.
- Si tu veux voir mes agents sur l'écran : Réglages › Agents › **Canal Claude**, active-le et donne-moi une fois le sujet ntfy et la clé de signature (tu peux régénérer la clé quand tu veux).

### Limites connues
- Sans incidence sur le reste : seul le Canal Claude était concerné.
